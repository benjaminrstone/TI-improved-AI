# TI Improved AI

A Terra Invicta mod (BepInEx 5 + Harmony) that makes the opposition play to win within in-universe limits. The aliens concentrate force, remember what they have seen, raid your economy, run on a wormhole-limited budget, differ from campaign to campaign, and can win. The AI human factions build fleets and trade. Optionally, a stronger model directs every non-player faction every three months.

Targets game build 1.0.53b. Not released; it runs on a development copy of the game.

- `docs/DESIGN.md`: the design and the decisions behind it.
- `docs/HANDOFF.md`: current state and next steps.
- `docs/TESTING.md`: how changes are tested (unattended harness runs from fixture saves).
- `src/ImprovedAI/`: the plugin. `tools/`: build, deploy, run and analysis scripts. `lab/probes/`: test scenarios.
